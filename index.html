Deploying to Vercel in 3 Steps

Host this interactive portal, API endpoint, and showcase on Vercel with zero friction.

1️⃣

Push to Git / Import

Push your repository to GitHub or GitLab, then head to vercel.com/new and select this repository.

2️⃣

Set GEMINI_API_KEY

In your Vercel Project Settings, navigate to Environment Variables and add GEMINI_API_KEY with your key from Google AI Studio.

3️⃣

Click Deploy

Vercel automatically detects the static web showcase and the /api/generate serverless function. Your app is live with SSL in seconds!
